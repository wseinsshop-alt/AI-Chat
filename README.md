# AI Chat
### Обычный AI-чат в Telegram

**Один список моделей · Личная история · Текст, фото, голос и файлы**

[Установка](#install) · [Как пользоваться](#usage) · [Администратору](#admin) · [Требования](#requirements)

</div>

Все разрешённые API-панели объединяются в один список моделей. Пользователь выбирает модель и общается в той же переписке. Панель подключается автоматически; одинаковые модели из разных источников подписаны названием панели.

**Панелями управляют только администраторы.** Обычные пользователи не добавляют и не меняют URL, ключи, режим работы или выдачу доступа. Ранее добавленные ими панели остаются в базе, но не используются: доступ выдаётся к панелям действующих администраторов.

<a id="usage"></a>
## Общение

1. Отправь **/start**, создай личный пароль или войди.
2. Нажми **«🧠 Модели» на клавиатуре снизу**, выбери модель из доступных панелей.
3. Просто общайся: текст, фото с вопросом, голосовые и документы приходят в один чат.
4. Проси картинки или файлы прямо в сообщении. Ответы и вложения придут сюда же.

**Единственная команда — /start.** Меню, остановка, выбор модели, поиск и управление историей доступны кнопками под полем ввода. Если Telegram скрыл клавиатуру, открой её значком рядом с полем ввода. Старые команды не отправляются модели.

В главном меню нет отдельных режимов «Документы» и «Нарисовать». Например:

- «Напиши привет и скинь пдф файл».
- «Хочу увидеть лес на картинке».
- «Сделай презентацию про космос».
- «Пришли текст в PDF и DOCX».

Приложение умеет прикреплять настоящие **PDF, DOCX, XLSX, PPTX, TXT, MD, CSV, JSON, HTML и ZIP**, а также отправлять изображения фотографиями. **Картинки и файлы от ИИ приходят без служебных подписей** — «Изображение от ИИ», названия формата и подобных строк под вложением. Несколько вложений поддерживаются через структурированное описание от модели. Приложение обрабатывает его как данные; сгенерированный код не исполняется.

Картинки требуют поддержки API изображений и доступной модели рисования. Голосовые требуют распознавания речи; ответ приходит текстом или вложениями, озвучки нет. Одинаковая поддержка всех функций всеми моделями и панелями не гарантируется.

### Личная история

У каждого пользователя свои чаты, избранное, пароль и стиль ответа. Смена модели **сохраняет текущий разговор**, даже если новая модель находится в другой разрешённой панели. «✚ Новый чат» создаёт отдельную историю. Чужой чат нельзя открыть по ID или старой кнопке.

**Контекст текущего чата передаётся выбранному API-провайдеру.** Учитывай это при переключении между панелями. После отзыва панели пользователь не может продолжать привязанные к ней чаты. История сохраняется до удаления чата или панели.

Модель списка определяется парой «панель + API ID». Одинаковые названия не смешивают ключи и расходы. Автопереключение применяется только при явном отказе до начала ответа: HTTP 402 либо распознанный код исчерпанной квоты/баланса. Сначала используется та же модель в другой разрешённой панели, затем резервные модели по списку администратора. Тайм-ауты, неизвестные ошибки, обрывы потока и ошибки после начала ответа не повторяются автоматически.

<a id="admin"></a>
## Администратору

**Админка → Резервные модели → Порядок:** введи API ID резервных моделей по одному в строке, в порядке приоритета. Список сохраняется в локальном config.json как `failover_priority`; один дефис очищает его. Пока список пуст, резерв работает только с той же моделью в других панелях. Пример: сначала `gpt-4o-mini`, следующей строкой `deepseek-chat`. Пользователь получает резерв только из выданных ему панелей. Личные дневные лимиты и подписка по-прежнему соблюдаются.


**Админка → Панели:** добавь название, публичный HTTPS API base URL и ключ. Адрес страницы чата не всегда равен API-адресу; используй адрес из документации панели.

**Админка → Друзья:** добавь Telegram ID либо создай приглашение. Выдай срок подписки, затем в «Панели друга» разреши нужные панели. У друга появятся модели только этих источников. Подписка и разрешение на панель проверяются отдельно.

Админка управляет сроками 7/30/90 дней и бессрочным доступом, отключением друзей, выдачей панелей, резервными копиями, импортом и подтверждённой очисткой базы. Личные настройки пользователя не дают административных прав.

Каталог моделей загружается из всех разрешённых панелей, до четырёх источников параллельно; кеш действует 10 минут. Ошибка одного источника не скрывает исправные панели. Перед выбором модели и запросом разрешение проверяется повторно.

API-ключи остаются на сервере и шифруются Fernet. Расход общей панели идёт с баланса её владельца. Подписка ChatGPT не предоставляет API-баланс. Автоматической оплаты подписок нет. Денежный предел владельца задавай у API-провайдера: личные лимиты бота не заменяют общий лимит аккаунта.

<a id="requirements"></a>
## Системные требования

| Компонент | Небольшой бот | Рекомендуется для друзей и вложений |
|---|---|---|
| ОС установщика | Ubuntu 22.04+ / Debian 12+, systemd | Поддерживаемая версия этой ОС |
| Python | 3.10+ | Отдельное виртуальное окружение |
| CPU | 1 vCPU | 2 vCPU |
| RAM | 1 ГБ для небольшого текстового использования | 2 ГБ; 4 ГБ для одновременной обработки PDF, Excel и PowerPoint |
| Свободный диск сверх ОС | 2 ГБ | 5 ГБ и запас под базу и резервные копии |
| Сеть | Исходящий HTTPS, DNS, SSH для установки | Доступ к Telegram, GitHub, PyPI и всем API-панелям |
| Права | root или sudo для установщика | Один процесс на токен и каталог данных |

Это ориентиры, **не результаты нагрузочного теста**. Число пользователей, панелей, параллельных заданий и размер вложений влияют на память и время ответа. При малом объёме RAM уменьши `workers` и `max_file_mb` в конфиге. Базовые настройки: 4 рабочих задания и вложения до 10 МБ.

GPU и локальная нейросеть не нужны: генерация выполняется у API-провайдеров. Домен, webhook и входящий HTTP-порт не требуются: используется Telegram polling. PDF с кириллицей использует шрифты DejaVu, установщик добавляет их.

<a id="install"></a>
## Установка и обновление

На сервере:

```bash
curl -fsSL https://raw.githubusercontent.com/wseinsshop-alt/AI-Chat/main/install.sh -o /tmp/ai-chat-install.sh && sudo bash /tmp/ai-chat-install.sh
```

Из Windows PowerShell, заменив SERVER_IP:

```powershell
ssh -t root@SERVER_IP "curl -fsSL https://raw.githubusercontent.com/wseinsshop-alt/AI-Chat/main/install.sh -o /tmp/ai-chat-install.sh && bash /tmp/ai-chat-install.sh"
```

Первый запуск запрашивает только токен Telegram и ID администратора. Обновление сохраняет настройки, ключ, историю и базу, создаёт снимок перед переключением версии и пытается откатиться при ошибке запуска. После обновления отправь **/start**, чтобы получить новую нижнюю клавиатуру.

Данные: `/var/lib/ai-chat/` — settings.json, bot.db, secret.key, backups/ и restore-points/. Код: `/opt/ai-chat/`. Служба: `ai-chat.service`.

```bash
sudo systemctl status ai-chat --no-pager
sudo systemctl restart ai-chat
sudo journalctl -u ai-chat -n 40 --no-pager
```

Сменить токен/ID: `sudo bash /opt/ai-chat/install.sh --configure`.

## Форматы и ограничения

- Приём: PDF с текстовым слоем до 60 страниц; PPTX до 60 слайдов; DOCX, XLSX, TXT, MD, CSV, JSON, HTML и изображения.
- Анализ документа: первые 60 000 символов; Excel — первые пять листов, 1000 строк × 30 столбцов.
- Изображения: публичный HTTPS или base64, до четырёх за ответ; до 15 МБ и 24 мегапикселей на картинку. Внешние изображения загружаются без ключей панели, редиректов и доступа к локальным адресам.
- Файлы от модели: до четырёх вложений, суммарно 120 000 символов содержимого. PPTX — до 20 текстовых слайдов. ZIP — до 20 текстовых файлов с простыми именами без путей. HTML — статическая страница из экранированного текста.
- Модель должна корректно сформировать данные для вложений. При обрезанном или неверном формате бот сообщает об ошибке; пустой фиктивный файл не создаёт.
- Распознавание голоса с последующим ответом — отдельные API-вызовы. Рисование по описанию, переданному чат-моделью, также использует отдельный вызов API изображений. Автопереключение квот реализовано для текстовых/мультимодальных запросов chat/completions, включая создание документов; распознавание речи и генерация картинок используют собственные API и не повторяются автоматически.
- Остановка кооперативная: сеть может ждать до 60 секунд, при рисовании до 180 секунд между данными. Уже выполненную работу провайдер может учесть.

## Настройки

`config.json` сохраняется при обновлении. Основные параметры: `workers`, `max_file_mb`, `daily_tokens`, `daily_usd`, `prices`, `transcription_model`, `image_model`, `image_prices`, `system_prompt`. Неизвестный тариф при включённом USD-лимите блокирует операцию. Сутки учёта — UTC; оценка бота может отличаться от счёта провайдера.

`image_model: ""` включает выбор подходящей модели изображений из панели; для нестандартного ID укажи его явно. `image_prices` — цена за картинку по модели или ключу `base_url|model`.

Переменные среды: AI_CHAT_TOKEN, AI_CHAT_ADMIN_IDS, AI_CHAT_DATA_DIR, AI_CHAT_CONFIG. Секреты в публичный репозиторий не помещай.

## Резервные копии

Копии шифруются исходным secret.key. **Храни ключ отдельно от копии:** без него восстановление невозможно. Формат 5 сохраняет подписки, разрешения, личный стиль и выбор моделей; импорт старых форматов 2/3/4 поддерживается. Перед импортом и очисткой сохраняется локальная копия; нужны пароль и отдельное подтверждение. Переписка в SQLite хранится текстом, администратор сервера имеет доступ к данным.

Автокопии: по умолчанию семь последних. Снимки restore-points содержат секреты и требуют отдельного контроля места.

## Ручной запуск

```bash
git clone https://github.com/wseinsshop-alt/AI-Chat.git
cd AI-Chat
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python main.py --setup
.venv/bin/python main.py
```

Windows: используй `py -3 -m venv .venv` и `.venv\Scripts\python.exe`.
