AI Chat — AI-кабинет в Telegram для себя и друзей. Подключай несколько OpenAI-совместимых панелей, выбирай модели и обсуждай текст, фотографии и документы. Администратор выдаёт друзьям доступ на срок через меню.

**Подписка в боте — разрешение пользоваться ботом.** По умолчанию друг не получает чужих панелей. Администратор может выдать ему доступ к своим готовым панелям: API-ключ скрыт, запросы расходуют баланс владельца панели. Чаты, история, избранное и выбор модели у каждого личные. Подписка ChatGPT не предоставляет API-баланс; автоматической оплаты подписок в этой сборке нет.

<a id="requirements"></a>
## 🖥 Системные требования

| Компонент | Для небольшого личного бота | Рекомендуется для друзей и документов |
|---|---|---|
| ОС для установщика | Ubuntu 22.04+ или Debian 12+, systemd | Актуальная поддерживаемая версия этих ОС |
| Python | 3.10+ | Виртуальное окружение, создаётся установщиком |
| Процессор | 1 vCPU | 2 vCPU |
| Оперативная память | 1 ГБ | 2 ГБ; для крупных PDF/Excel — 4 ГБ |
| Свободное место сверх ОС | 2 ГБ | От 5 ГБ, с запасом под историю и копии |
| Сеть | Исходящий HTTPS к Telegram, GitHub, PyPI и API-панелям; рабочий DNS | Стабильное соединение без блокировки этих сервисов |
| Права | root или sudo для установки службы | SSH-доступ для управления |

CPU, RAM и диск — ориентиры для начала, а не измеренные пределы нагрузки. Потребление растёт с числом одновременных запросов, размером документов и резервных копий. Само приложение ограничивает размер вложений, но обработка файлов требует дополнительной памяти.

**Видеокарта и локальная языковая модель не требуются:** генерация выполняется у API-провайдера. Нужны токен Telegram, ID администратора и API-ключ панели с доступными моделями и балансом. Для PDF с кириллицей установщик добавляет `fonts-dejavu-core`. Домен, публичный HTTP-порт и входящие порты для бота не нужны: используется polling; SSH нужен только для администрирования.

При ручном запуске возможны Windows/macOS с Python 3.10+ и зависимостями из `requirements.txt`; автоматический установщик и служба systemd предназначены для Linux.

<a id="install"></a>
## 🚀 Установка на VPS

Нужны Ubuntu 22.04+ или Debian 12+ с systemd, Python 3.10+, токен от [@BotFather](https://t.me/BotFather) и числовой Telegram ID владельца.

Выполни на сервере одну строку:

```bash
curl -fsSL https://raw.githubusercontent.com/wseinsshop-alt/AI-Chat/main/install.sh -o /tmp/ai-chat-install.sh && sudo bash /tmp/ai-chat-install.sh
```

Установщик попросит **только токен и Telegram ID**, создаст окружение и запустит службу `ai-chat` с автозапуском. Токен вводится скрыто. На обновлении настройки используются повторно. Если curl отсутствует: `sudo apt update && sudo apt install -y curl`.

Из **Windows PowerShell** (замени SERVER_IP адресом VPS):

```powershell
ssh -t root@SERVER_IP "curl -fsSL https://raw.githubusercontent.com/wseinsshop-alt/AI-Chat/main/install.sh -o /tmp/ai-chat-install.sh && bash /tmp/ai-chat-install.sh"
```

После установки можно закрыть SSH. Домен, входящие порты и webhook не нужны.

### Первый разговор

1. Отправь боту `/start`, создай личный пароль и повтори его.
2. Открой **«📚 Панели» → «✚ Своя панель»**, введи название, API base URL и API-ключ.
3. Выбери модель в **«🧠 Модели»**. Кнопка «☆ Сохранить» рядом с моделью добавляет её в избранное. Выбор модели запоминается отдельно для каждой твоей панели.
4. Пиши вопросы, отправляй фото с подписью, документы или голос.

Нужен API-адрес из документации панели, например `https://example.com/v1`. Страница `/chat` преобразуется в `/v1`, но у конкретного провайдера API может находиться по другому адресу. Поддерживается публичный HTTPS.

## 👥 Друзья и подписки

**«🛠 Админка» → «👥 Друзья»** — список людей и управление доступом.

| Действие | Результат |
|---|---|
| ✚ Друг по ID | Можно выдать доступ человеку до первого входа |
| 7, 30, 90 дней | Выдать или продлить срок; активная подписка продлевается от даты её окончания |
| Без срока | Бессрочный доступ |
| Отозвать | Новые запросы блокируются; данные человека сохраняются |
| Приглашение | Одноразовая ссылка на 24 часа, срок подписки выбирается отдельно |
| Мой доступ | Пользователь видит свой статус и срок |

Друг открывает бота и задаёт **свой пароль**. Доступ проверяется перед запуском обработки и резервированием расхода. Уже отправленный провайдеру запрос может завершиться после отзыва. При истечении срока остаются меню и статус, новые запросы к ИИ блокируются.

Администраторы имеют бессрочный доступ. При обновлении существующие пользователи и ранее допущенные ID получают бессрочный доступ, чтобы не отключить действующие аккаунты. Затем их можно перевести на срок или отключить в админке.

<a id="interface"></a>
## 🎨 Меню без путаницы

На основных экранах — по две кнопки в строке и короткие подписи. Длинные списки разбиты на страницы с парными кнопками «Назад / Далее». При переходе меню обновляется в том же сообщении; ответы ИИ остаются отдельными сообщениями без панели действий. После нового сообщения пользователя следующее меню открывается внизу переписки.

| Куда нажать | Что произойдёт |
|---|---|
| 💬 Продолжить | Откроет текущий личный чат; если настройка не закончена, покажет следующий шаг |
| 🧠 Модели | Выбор модели, поиск и избранное; после выбора можно сразу писать |
| 📚 Панели | Свои и выданные панели; название выбирает панель, кнопка справа открывает сведения |
| 🗂 Мои чаты | Продолжение переписки, переименование и экспорт через «Настроить» |
| 📄 Документы | Формат файла и запрос на его создание |
| 🖼 Нарисовать | Описание картинки; бот найдёт модель изображений в выбранной панели |
| ⚙️ Настройки → ✍️ Стиль ответа | Обычный, краткий или подробный стиль, личный для каждого пользователя |
| 🛠 Админка → 👥 Друзья | Срок доступа, состояние регистрации и число выданных панелей |

В карточке друга есть две отдельные настройки: срок подписки и **«🤝 Панели друга»**. В списке панелей левая кнопка открывает сведения, правая **«＋ Выдать»** даёт доступ, а **«✓ Разрешена»** отзывает его.

Стиль ответа добавляется к системной подсказке без отдельного API-вызова. Панель и модель должны поддерживать системные инструкции. Личный выбор модели применяется к новым чатам и не меняет модель в уже существующих разговорах других пользователей.

Telegram управляет фактическим размером кнопок и оттенками цветов. В старых клиентах оформление может отличаться, но подписи и состояние ✓ остаются понятными.

## 🖼 Текст, голосовые, фотографии и готовые файлы

Просто отправляй сообщения в личный чат бота:

| Что отправить | Что делает бот |
|---|---|
| Обычный вопрос | Отвечает текстом в чате |
| Фотографию с вопросом в подписи | Передаёт фото выбранной vision-модели и отвечает в чате |
| Голосовое сообщение | Распознаёт речь через панель и выполняет просьбу; голосом не отвечает |
| «Нарисуй кота на луне» | Запрашивает изображение и присылает фотографию в Telegram |
| «Нарисуй лес файлом» | Присылает оригинал изображения как файл |
| «Напиши привет и скинь пдф файл» | Создаёт настоящий PDF и показывает короткий текст в подписи |
| «Пришли рассказ файлом» | Создаёт TXT, если формат не указан |
| «Сделай PDF про космос» | Создаёт и присылает PDF; поддерживаются также DOCX, XLSX, TXT, MD и CSV |
| Фото с подписью «Сделай PDF по этой задаче» | Анализирует фото и создаёт документ с ответом |

Разговорные просьбы «скинь», «пришли», «сформируй», «отправь» тоже запускают создание файлов. Понимаются названия «пдф», «пдфка», Word/ворд, Excel/эксель, PDF, DOCX, XLSX, TXT, CSV, Markdown/MD; DOC и XLS преобразуются в современные DOCX и XLSX. Порядок слов свободный. Обычный вопрос о формате, например «Чем отличается PDF от DOCX?», остаётся текстовым вопросом.

**Поддержка зависит от API-панели.** Для фото нужна vision-модель; для голосовых — `/audio/transcriptions`; для рисования — `/images/generations` и модель изображений. Если сервис этого не предоставляет, установка бота не добавляет такую возможность. Встроенной озвучки и кнопки «Озвучить» нет.

При просьбе нарисовать бот использует `image_model` из конфига, выбранную модель изображений или первую подходящую по ID из списка панели. Для автоматического определения распознаются gpt-image, dall-e, flux, imagen, ideogram, seedream, recraft, sdxl и stable-diffusion. Если у модели другое название, выбери её через конфиг `image_model`. Модель обычного чата и личный выбор не меняются.

Бот также принимает изображения из ответов `/chat/completions`: поля `images`, блоки `image_url` в `content` и Markdown-картинки. Принимаются base64 и публичные HTTPS-ссылки; внешние изображения загружаются без API-ключей панели, без редиректов и доступа к локальным адресам. До четырёх изображений в ответе, до 15 МБ и 24 мегапикселей на картинку. В историю записывается текстовая отметка, а не большой base64-файл.

Запрос изображения отправляется один раз. Ожидание API рисования может занять до 180 секунд между получениями данных; остановка кооперативная, провайдер может учесть уже выполненную работу. Голосовое с последующим ответом — два отдельных API-вызова.

Пример дополнительных настроек в `config.json` (цена **условная**, укажи тариф своего провайдера):

```json
{
  "transcription_model": "whisper-1",
  "image_model": "",
  "image_prices": {"your-image-model": 0.04}
}
```

`image_prices` задаёт USD за одну картинку; можно использовать ключ `base_url|model`. При включённом личном USD-лимите и неизвестной цене рисование блокируется до настройки тарифа. Значение `image_model: ""` включает выбор из моделей панели.

Формат запроса изображений сверяется с [официальной справкой OpenAI](https://developers.openai.com/api/reference/resources/images/methods/generate). Совместимые панели могут поддерживать только часть протокола.

<a id="configuration"></a>
## ⚙️ Настройки и данные

```text
/opt/ai-chat/          main.py, config.json, requirements.txt, install.sh, README.md
/var/lib/ai-chat/      settings.json, bot.db, secret.key, backups/, restore-points/
```

`settings.json` содержит токен и ID владельцев. `config.json` задаёт регистрацию, личные лимиты, тарифы, модели голоса и системную подсказку. Установщик сохраняет существующий конфиг. Для изменения токена и ID:

```bash
sudo bash /opt/ai-chat/install.sh --configure
```

| Переменная | Назначение |
|---|---|
| `AI_CHAT_TOKEN` | Токен Telegram |
| `AI_CHAT_ADMIN_IDS` | ID владельцев через запятую |
| `AI_CHAT_DATA_DIR` | Каталог данных |
| `AI_CHAT_CONFIG` | Путь к конфигу |

При ручном запуске данные по умолчанию находятся в `~/.local/share/ai-chat` на Linux или `%LOCALAPPDATA%\AIChat` на Windows. Один токен и каталог данных должны обслуживаться одним процессом.

### Расходы

`daily_tokens` — начальный дневной лимит; `daily_usd: 0` отключает USD-лимит. Пользователь меняет свои лимиты через меню. Для USD-лимита нужны цены за миллион токенов в `prices`. Пример с **условными** тарифами:

```json
{"prices": {"your-model-id": {"input": 1.0, "output": 3.0}}}
```

Ключ `base_url|model` задаёт цену для конкретной панели. Неизвестный тариф при включённом USD-лимите блокирует обращение. Для голосовых задан отдельный тариф `transcription_usd_per_minute`; для рисования — `image_prices`. Старые настройки озвучки больше не используются.

Сутки считаются по UTC. Если провайдер вернул usage, используется он; при отсутствии usage, отмене или сбое учитывается консервативная оценка. Локальный лимит не гарантирует точность счёта провайдера — денежный предел задавай также в самой панели.

### Вложения

PDF: текстовый слой, до 60 страниц; скан отправляй фотографией vision-модели. XLSX: первые пять листов, до 1000 строк × 30 столбцов; в анализ идут первые 60 000 символов. Фото уменьшается до 1600 × 1600 и передаётся как base64 без URL с токеном Telegram. Создание файлов поддерживает простые заголовки и абзацы, сложная верстка Markdown ограничена. Распознавание голоса требует `/audio/transcriptions`; распознавание с последующим ответом — два API-вызова.

<a id="update"></a>
## 🔄 Обновить и перезапустить

Повтори команду установки. Перед переключением кода установщик останавливает службу и сохраняет снимок SQLite. Настройки и данные сохраняются. При ошибке запуска установщик пытается вернуть прежний код, systemd unit и снимок базы. Каталог `restore-points/` содержит секреты и доступен владельцу сервера.

```bash
sudo systemctl status ai-chat --no-pager
sudo systemctl restart ai-chat
sudo journalctl -u ai-chat -n 40 --no-pager
```

Установщик обнаруживает прежний `/opt/tg-ai-cabinet`, переносит базу и ключ и отключает прежнюю службу после успешного запуска. Для другого пути перенеси `bot.db` и `secret.key` при остановленных процессах и укажи прежний токен.

<a id="backup"></a>
## 💾 Копии и восстановление

Экспорт из админки создаёт зашифрованный `.enc`-файл. **Сохраняй secret.key отдельно**: без него нельзя открыть ключи панелей и копию. Копии версии 5 сохраняют выданные панели, личный стиль и выбранные модели. Версии 2/3/4 тоже импортируются: новые личные настройки получают обычные значения; формат 4 сохраняет выданные панели. Пароль хранится как PBKDF2-хеш, ключи шифруются Fernet; переписка хранится в SQLite как текст. Администратор сервера имеет доступ к данным.

Импорт требует личный пароль, проверенный файл и отдельное подтверждение. Сначала создаётся локальная копия, затем заменяется БД и сбрасываются сеансы. Формат 2 принимается с бессрочным доступом прежних аккаунтов. Копию формата 5 нужно восстанавливать в этой или более новой совместимой версии бота.

**«Очистить базу»** требует пароль и второе подтверждение. Сначала сохраняется зашифрованная копия, затем удаляются пользователи, панели, чаты, приглашения, подписки и статистика. После очистки начни с `/start`. Отмена делает старое подтверждение недействительным.

Автокопии хранятся в `backups/`, по умолчанию семь последних. Сохраняй экспорт отдельно от VPS, чтобы пережить потерю сервера.

## 💻 Ручной запуск

```bash
git clone https://github.com/wseinsshop-alt/AI-Chat.git
cd AI-Chat
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
```

В Windows создай окружение через `py -3 -m venv .venv`, затем вместо `.venv/bin/python` используй `.venv\Scripts\python.exe`. На Linux для PDF с кириллицей нужен пакет `fonts-dejavu-core`.

**Нет админки:** проверь ID в settings.json и перезапусти службу. **Нет ответа:** проверь API URL, баланс и поддержку chat/completions. **Истёк доступ:** владелец продлевает его в друзьях. **Conflict:** останови вторую копию. **Стоп занимает время:** чтение сети может ждать до 60 секунд, возврат оплаты провайдером не гарантируется. Автоматического повтора платного запроса нет.

<a id="sharing"></a>

## 🤝 Выдать другу готовую панель

1. **Админка → Друзья → ✚ Друг по ID**. Выдай другу срок доступа.
2. В карточке друга нажми **«🤝 Панели друга»**. Нажми «＋ Выдать» напротив нужной панели. Кнопка «✓ Разрешена» означает, что доступ включён; нажатие отзывает его.
3. Друг открывает **/start → Панели**, выбирает выданную панель, затем модель и пишет сообщение.

Выдавать можно только собственные панели. Друг получает все модели выбранной панели, не видит API-ключ и не может менять настройки владельца. У каждого свои чаты, файлы истории, избранное и выбор модели. Общая переписка не включается. Изменение ключа владельцем применяется и для друзей. При отзыве панели её старые чаты сохраняются, но открыть их или продолжить запрос через неё нельзя; текущий запрос получает сигнал остановки. Уже выполненную работу провайдер может учесть.

Подписка и разрешение на панель — разные настройки: для генерации другу нужны обе. Панель можно выдать по ID заранее; после регистрации друг найдёт её в списке. Дневные лимиты учитываются для пользователя, который отправил запрос; его настройки не являются общим денежным пределом владельца. Общий предел расходов устанавливай у API-провайдера.

Основные и навигационные кнопки синие, выданные панели зелёные, отключение и удаление красные. Списки панелей имеют страницы. После обычного ответа нет карточки действий с озвучкой и повтором.
